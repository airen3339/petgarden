# petgarden
一个可落地的 3D 宠物纪念平台：前台 3D 园区可漫游、换装、献礼、多人同屏；用户可为宠物建立纪念馆、挑选墓碑款式、把宠物照片留在碑上；管理后台负责内容审核、商品订单与实时监控；移动端 App / H5 / 小程序随时进园。

## 1. 产品定位

宠物纪念园是一个「3D 园区 + 纪念馆 + 纪念服务」的线上平台：

- **用户**：为离世宠物建立纪念馆，在 3D 园区中拥有一块墓碑，随时进入园区祭奠、献礼、与其他访客同屏互动。
- **访客**：无需注册即可进入园区，以随机昵称漫游、查看公开纪念馆并献礼。
- **运营方**：通过管理后台审核内容、管理用户与订单、调整园区与墓位价格、配置邮件/短信与支付。

需要明确：本平台提供的是**数字纪念服务**，不包含实体安葬、火化或任何线下殡葬服务。

## 4. 账号与身份

### 4.1 注册与登录

- **邮箱注册**：填写邮箱 → 获取验证码 → 设置昵称与密码（至少 8 位，建议含字母与数字）→ 确认年满 18 周岁或已取得监护人同意 → 同意昵称公开展示。
- **验证码**：6 位数字，默认 5 分钟有效；同一邮箱 60 秒内不可重复发送，每小时最多 5 次。
- **开发模式**：未配置邮件服务时，接口会在响应中返回 `dev_code`，页面直接显示验证码；生产环境未配置邮件服务会返回明确错误。
- **登录状态**：访问令牌过期会自动使用刷新令牌续期；只有服务端明确返回 401/403 才会退出登录。
- **找回密码**：邮箱验证码校验通过后可重置密码，并吊销该账号所有已登录会话。

### 4.2 访客身份

- 未登录用户进入园区时，服务端从两字昵称池中分配一个**全局不重复**的随机昵称（每批 3000 个，用完自动生成下一批；两字组合耗尽后回收 90 天未使用的昵称）。
- 同一浏览器通过本机 `pg_client_id` 保持同一昵称，便于献礼记录署名；同时在线重名时自动追加序号。
- 访客可以献礼，献礼记录会保留其随机昵称。

### 4.3 账号注销

- 提交注销后进入 **7 天冷静期**（可在后台调整），期间可撤销；到期由后台任务清理。

## 5. 宠物档案

- 支持为多只宠物建立档案：昵称、类别、品种、性别、出生日期、离开日期、头像、小故事。
- 宠物档案集中在「个人资料」页管理，可新增、编辑、删除。
- 若宠物已绑定纪念馆，需先删除对应纪念馆才能删除宠物档案。

## 6. 纪念馆与墓位

### 6.1 建馆流程

1. 选择一只宠物（或先创建宠物档案）。
2. 在 3D 园区选择空墓位，或由系统自动分配。
3. 选择墓碑造型、填写墓志铭、设置可见性。
4. 确认费用并支付（有免费名额时费用为 0）。
5. 纪念馆进入待审核状态，审核通过后在园区与列表公开展示。
6. 创建成功后自动进入 3D 园区并站到自己的墓碑前，墓碑带橙色「审核中」标识，无需自己再寻找。

### 6.1.1 我的墓碑与一键到达

- 登录用户进入园区时，除公开纪念馆外还会拉取本人全部纪念馆（含待审核、私密、仅链接可见），合并去重后渲染。
- 本人墓碑上方有金色光柱、地面光环与「我的纪念碑」悬浮标签；审核中为橙色，并显示「审核中 · 我的纪念碑」。光柱与标签仅本机可见。
- 待审核的纪念馆，其他访客也能在园区看到墓碑占位，并在上方显示橙色「审核中」标识；不展示馆名、简介、宠物造型与照片，也不能点开详情，避免提前泄露未审核内容。
- 审核通过后，占位墓碑自动变为正常纪念馆；删除申请冷静期内的纪念馆不再显示。
- 园区右上角「我的墓碑」按钮：未登录不显示；无纪念馆时引导创建；1 座纪念馆直接传送；多座纪念馆展开列表供选择。
- 传送后角色站到墓碑前，镜头朝向墓碑；创建成功跳转 `/garden?mine=1` 时同样自动定位。
- 顶部横幅在有审核中的纪念馆时提示「你有 N 座纪念馆正在审核中，已用橙色光柱标出位置」，可关闭。
- 纪念馆卡片为本人显示「我的纪念馆」徽标，审核中显示「审核中」，并提供「前往墓碑」按钮。
- 移动端 App/H5 行为一致（HUD「我的墓碑」按钮）；微信小程序 2D 地图用金色「我」标记并支持点击查看。

### 6.2 墓位与价格

园区包含三个区域：

| 区域 | 说明 | 默认价格 |
| --- | --- | --- |
| 入口区 | 大门与主步道，不设墓位 | — |
| 中央花园区（C 区） | 中央环路外圈，祭品范围更大 | 99 萤火币 |
| 宠物纪念区（含草坪区 G 区） | 成排草坪墓位，园区主力区域 | 首个普通墓位免费，再次创建 88 萤火币 |

- 以上价格与「首个普通墓位免费」开关均可在管理后台「设置 → 墓位价格」中调整，前台标价与说明实时读取后台配置。
- C 区墓位不参与首次免费名额，始终按标价收费。
- 墓位价格从萤火币余额扣除，余额不足时无法完成建馆。

### 6.3 纪念馆设置

- 名称、墓志铭、宠物照片、故事、相册。
- 可见性：公开 / 仅链接可见 / 私密。
- 访问口令：可设置 4–32 位口令，访问时需输入。
- 允许访客献礼：关闭后仅馆主与协作者可献礼。
- 删除纪念馆：进入 7 天冷静期，期间可撤销。

- 馆主可生成邀请链接，为亲友分配 `admin`（管理成员与内容）、`editor`（编辑内容）、`viewer`（只读）角色。
- 协作者可查看纪念馆后台与献礼记录，权限不足时接口返回 403。

## 7. 3D 纪念园区

- **漫游**：WASD / 方向键移动，鼠标或触屏拖动转向，点击地面自动行走，支持第一/第三人称。
- **区域提示**：左上角实时显示当前所在区域（入口区 / 中央花园区 / 宠物纪念区），随角色坐标变化。
- **墓碑交互**：点击墓碑打开纪念馆卡片，可查看详情、献礼或进入纪念馆；碑面按所选款式渲染，有照片时展示照片与相框。
- **碰撞**：角色不可穿过墓碑、围墙、树木与建筑；墓位占地按带旋转矩形计算。
- **多人同屏**：WebSocket 实时同步，分区与分线，单分区软上限 30 人、硬上限 50 人；支持表情、预设短语与隐身。
- **换装**：40 件部件（发型、上装、下装、鞋、配饰），可调体型与肤色；免费换装无需登录，造型保存在本机并在园区生效。
- **墓位范围提示**：点击墓碑或空墓位时在地面绘制祭品摆放范围（虚线标识），C 区范围默认大于 G 区，宽/深可在后台「墓园场景」中调整；Web 与手机端 App/H5 使用同一套范围绘制。
- **我的墓碑标识**：本人纪念馆上方显示金色光柱、地面光环与「我的纪念碑」悬浮标签，审核中为橙色；标识仅本人客户端可见，不遮挡墓碑点击。
- **一键到达**：园区「我的墓碑」按钮可直接传送到本人墓碑前并调整镜头朝向；多座纪念馆时可选择目标；`?mine=1` 与 `?memorial=<slug>` 均支持自动定位。
- **软广告位**：园区内「福运盘」摆件，点击新窗口打开 <http://www.fuyunpan.cn>。

## 8. 献礼与祭品 30 天规则

- 任何访客或用户都可以向公开纪念馆献礼，可选择实名或匿名。
- 每件祭品从放置时刻起独立计算 **30 天**有效期；到期后自动从墓碑前消失，但记录保留。
- 墓碑主人可以在「我的祭品记录」查看自己收到的全部祭品及其剩余天数。
- 献礼者可以在「献礼记录」查看自己送出的祭品。
- 馆主可查看该纪念馆的祭品统计：有效数量、已过期数量、累计有效天数。
- 到期清理由后台 worker 定时执行，同时查询接口会按 `expires_at` 过滤，保证到期即不再展示。

## 9. 萤火币与商城

- **萤火币**：站内虚拟币，1 萤火币 = 1 元人民币，名称可在后台修改。
- **获取**：每日签到（默认 1 萤火币，后台可调）、充值。
- **充值方式**（后台切换）：
  - 二维码收款：展示支付宝/微信收款码，用户提交金额与付款凭证，管理员审核后到账。
  - 支付参数收款：配置支付宝/微信商户参数后在线支付，回调自动到账。
- **消费场景**：墓位、换装部件、祭品、商城商品、墓碑款式、照片相框。
- **商城**：商品列表/详情、下单、支付、订单超时自动关闭（默认 30 分钟）、7 天内可申请退款（后台可调）。
- 墓碑款式与照片相框在商城「墓碑款式与照片相框」区块展示，购买入口同时出现在纪念馆编辑页。

## 11. 关键业务规则

| 规则 | 说明 |
| --- | --- |
| 祭品有效期 | 30 天，按单件放置时间独立计算，到期隐藏但保留记录 |
| 首个墓位免费 | 每个账号第一次在非 C 区建碑免费，可在后台关闭 |
| C 区收费 | 始终按后台设置的 C 区价格收费，不占免费名额 |
| 付费款式 | 一次购买永久拥有；未拥有时选择返回 409 `E-6402`；退款回收并回退纪念馆 |
| 访客昵称 | 服务端统一分配，两字、全局不重复、每批 3000 个 |
| 纪念馆删除 | 7 天冷静期，可撤销 |
| 账号注销 | 7 天冷静期，可撤销 |
| 订单超时 | 默认 30 分钟未支付自动关闭 |
| 退款窗口 | 支付后 7 天内可申请 |

## 12. 移动端（微信小程序 / Android / iOS / H5）

移动端位于 `apps/mobile`，使用 uni-app（Vue 3 + TypeScript + Vite），与 Web 共用同一套后端接口与业务规则。

| 功能 | 小程序 | App | 说明 |
| --- | --- | --- | --- |
| 邮箱注册/登录 | 支持 | 支持 | 与 Web 共用账号 |
| 微信小程序一键登录 | 支持 | — | 服务端 `jscode2session` 换取 openid，未配置 AppID 时隐藏入口 |
| Apple 登录 | — | iOS 支持 | 校验 Apple `identity_token` 与 JWKS；未配置 Bundle ID 时隐藏入口 |
| 首页 / 纪念馆列表 / 详情 / 献礼 | 支持 | 支持 | 献礼沿用 30 天有效期与审核规则 |
| 创建纪念馆 / 宠物档案 | 支持 | 支持 | 支持选位、款式选择（含购买）、显示后台墓位价格与首碑免费规则 |
| 个人中心 / 钱包签到 | 支持 | 支持 | 余额与充值记录只读 |
| 园区浏览 | 2D 俯视地图 | 完整 3D | App/H5 通过 renderjs 运行与 Web 相同的 three.js 场景（拖动旋转、双指缩放、点击地面移动、点击墓碑显示地面虚线范围与底部操作卡，墓碑进详情、空位直接建馆），并与 Web 共用 12 款墓碑 + 10 款相框渲染；小程序首版保持 2D |
| 虚拟币充值 | 默认关闭 | 待接入 | 小程序需虚拟支付资质；iOS 必须走 App Store 内购 |

平台合规约束：微信小程序 iOS 端不提供虚拟支付；iOS App 的虚拟币充值只能通过 IAP，服务端 `POST /payments/iap/verify` 已完成收据校验与幂等入账，客户端内购入口随 M3 上线。

## 13. 技术特性

- **前后端分离**：Go API、独立 WebSocket 网关、独立定时任务进程；管理后台与前台、H5 由同一 nginx 分发。
- **3D 全程序化**：`packages/garden-core` 使用 Three.js 几何体 + CanvasTexture 生成园区、12 款墓碑、10 款相框与照片贴图，无需外部模型文件；Web 与移动端 App/H5 共用同一份代码。
- **实时同步**：10Hz 状态广播，msgpack 编码，Redis Pub/Sub 支持多实例。
- **安全**：JWT 双令牌、接口限流、越权校验、上传类型与大小限制、管理员操作审计。
- **数据**：PostgreSQL 持久化，Redis 缓存与限流，MinIO/本地磁盘存储上传文件。
- **可配置**：园区尺寸、墓碑范围、墓位价格、墓碑/相框收费开关、邮件/短信、支付方式均无需改代码。
- **多端**：Web 与 uni-app 移动端共用 `packages/shared` 类型与 `packages/api-client` 请求层，一套代码编译到微信小程序、Android、iOS 与 H5。
